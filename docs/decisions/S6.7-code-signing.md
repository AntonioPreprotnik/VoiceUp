# S6.7 — Do we pay to sign the Windows installer, or ship it unsigned?

Date: 2026-11-06 · Status: decided

## Decision
VoiceUp ships unsigned for now. Each release publishes `SHA256SUMS.txt`, and `docs/install.md` walks a friend past the SmartScreen warning with "More info → Run anyway". Antonio chose this on 2026-11-06. Only he and one friend use the app, and money goes in only if the product proves itself. The triggers for revisiting are under Consequences.

## Evidence
This is a cost-and-policy question, so the evidence is from published sources, checked on 2026-11-06, not from measurements. Prices change, so check them again before buying.

| Option | Cost | Removes the warning? | Notes |
| --- | --- | --- | --- |
| Unsigned + guide | Free | No. SmartScreen shows "Windows protected your PC" on a downloaded installer, every release | One extra click per install. Smart App Control blocks it outright (see below) |
| Microsoft Artifact Signing (formerly Trusted Signing) | $9.99/month (Basic, 5,000 signatures) | Not immediately. Reputation builds over time | Individual developers: USA and Canada only. Organizations: also EU and UK. Antonio is an individual in Croatia, so he can't use it |
| Certum Open Source Code Signing | From €69 for the certificate. €359 with a card and reader. A cloud key (SimplySign) is another option | Not immediately | Issued to a person, for open-source projects. Certum says it builds SmartScreen reputation. VoiceUp has no open-source license yet |
| Commercial OV certificate (Sectigo, SSL.com, …) | About $150–300 a year, per Microsoft's own guidance | Not immediately | The key must sit on a hardware token or in a cloud key service. That rule comes from the CA/Browser Forum baseline requirements, June 2023. Here it was confirmed only from vendor material |
| EV certificate | More than OV | **No longer.** Since August 2024 Microsoft treats EV and OV the same for SmartScreen | Microsoft: paying for EV only to avoid SmartScreen is "no longer justified" |
| SignPath Foundation (free for open source) | Free | Not immediately | Needs an OSI open-source license and an approved project. VoiceUp has no license file, so it isn't eligible |

Facts that drive the decision:

- **Signing no longer removes the warning on its own.** OV and EV signed files both have to earn SmartScreen reputation through downloads. A signed app with a few installs can still warn, so for two users a certificate buys little.
- **Smart App Control is the one real blocker.** On a Windows 11 PC where it's on (it starts in evaluation mode on clean installs), an app it can't judge must have a valid signature or it's blocked. There's no "Run anyway" and no per-app exception. The only fix is turning Smart App Control off in Windows Security, and that can't be undone without resetting Windows. Antonio's PC runs Windows 10, which doesn't have it. A friend's Windows 11 PC might, so `docs/install.md` says how to check.
- **Updates are not affected.** S7.4 already records that unsigned builds update through `electron-updater`. SmartScreen checks files marked as downloaded from the internet in Explorer or a browser. Whether an update downloaded by the app shows it is for S7.4 to confirm on the VM.

## Environment
Windows 10 Home 22H2 (19045), AMD Ryzen 5 3600, 16 GB RAM, Electron 45.2.1, electron-builder 26.18.1. Today's packaging prints "no code signing certificate configured, signing is skipped" for `VoiceUp.exe` and the bundled `OpenConsole.exe`, which is expected.

## Consequences
- `electron-builder.yml` stays as it is: no `win.signtoolOptions`, no `publisherName`, and no signing secrets in CI.
- **S7.3:** the manual checklist installs from a browser download on the clean VM and checks that the guide's steps match what Windows shows.
- **S7.4:** confirm on the VM that an app-downloaded update installs without a SmartScreen prompt.
- **Release (§7.3):** each GitHub Release body links `docs/install.md` next to `SHA256SUMS.txt`.
- **When to revisit:** more than a handful of users, a friend on Smart App Control who won't turn it off, or anyone outside the friends group. The likely first step is Certum Open Source (€69 or more), after adding an open-source license. Artifact Signing becomes possible if Microsoft opens it to individuals in the EU. Signing then goes in `win.signtoolOptions` or `azureSignOptions` with the secret in CI, and gets its own story.
- TECH_SPEC §7.2 and §7.3 now say the app ships unsigned and that releases link the guide.

## Rejected options
- **Artifact Signing:** not available to an individual in Croatia.
- **Certum Open Source:** costs money, needs an open-source license, and still warns until reputation builds. It's the first choice once VoiceUp has more users.
- **Commercial OV certificate:** the highest yearly cost, with the same warning at first.
- **EV certificate:** no longer earns instant SmartScreen reputation, so the extra cost buys nothing here.
- **SignPath Foundation:** VoiceUp isn't open source.
